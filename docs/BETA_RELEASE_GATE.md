# GunnchOS Beta Release Gate

**Gate ID:** `beta` (operational definition)  
**Status:** `not_met`  
**Last updated:** 2026-07-02

This document defines what must be **true** before GunnchOS may be called **beta**. It supplements [release_gates/BETA_GATE.md](../release_gates/BETA_GATE.md) with Phase 1+ operational detail.

---

## Beta claim allowed when ALL of the following pass

### 1. Installable artifact

| Requirement | Evidence | Current |
|-------------|----------|---------|
| Internal OS-layer package **or** bootable image prototype | Install log on reference hardware or VM | **Missing** |
| Uninstall/upgrade path documented | Runbook + test log | **Missing** |
| Version manifest generated by CI | `results/` or release artifact | **Partial** (SBOM scripts exist) |

### 2. Campus Mode basics (functional, not mock)

| Requirement | Evidence | Current |
|-------------|----------|---------|
| First boot → Campus Mode works | Vitest + manual smoke | **Prototype** ✓ |
| Real file manager or scoped storage | CRUD test on real files | **Mock** |
| Functional notes app | Persist note across restart | **Missing** |
| Settings persistence | Settings survive restart | **Partial** (localStorage profile only) |
| Browser/PWA opens real URLs | E2E URL load | **Mock** |

### 3. Media Mode (minimum)

| Requirement | Evidence | Current |
|-------------|----------|---------|
| YouTube route works (browser/webview) | Smoke test | **Prototype** (external link) |
| Local media plays non-DRM file | Playback test | **Mock** |
| Netflix/Hulu show DRM disclaimer | Vitest assertion | **Real** ✓ |
| No false streaming certification claims | Doc + UI audit | **Real** ✓ |

### 4. Game Mode (minimum)

| Requirement | Evidence | Current |
|-------------|----------|---------|
| Launches at least one real game build | Launch log + screenshot | **Mock** |
| Exit returns to Game library without crash | Vitest mode switch | **Prototype** ✓ |
| First-party games listed | UI present | **Real** ✓ |

### 5. Policy & tests

| Requirement | Evidence | Current |
|-------------|----------|---------|
| Python→React contract export automated in CI | CI workflow step | **Partial** (script exists; CI wiring TBD) |
| Frontend tests in CI | `npm test` green in Actions | **Partial** |
| Python tests in CI | `pytest` green | **Real** ✓ |
| Media/school/offline policy tests | `tests/test_media_policy.py` | **Real** ✓ |

### 6. Honesty & operations

| Requirement | Evidence | Current |
|-------------|----------|---------|
| Known issues list published | `docs/KNOWN_ISSUES.md` or release notes | **Missing** |
| No false secure boot / hardware claims | Claim boundary audit | **Real** ✓ |
| No false streaming certification | UI + docs audit | **Real** ✓ |
| No DRM circumvention | Code + doc audit | **Real** ✓ |
| README status table accurate | README review | **This PR** |

---

## Beta forbidden claims

- Release candidate or GA
- Production-ready for all SKUs
- Official Netflix/Hulu/Disney+ certification
- Secure boot complete / TPM validated
- Hardware-validated across fleet
- Production MDM deployed
- Accessibility conformance certified

## Beta validation commands

```bash
# Policy export
python3 scripts/export_launcher_contract.py

# Python
pytest -q

# Frontend
cd apps/launcher_mock && npm install && npm run build && npm test

# Full repo smoke
make e2e
```

- [ ] Security: no new false claims introduced
- [ ] Product: beta scope documented in release notes
