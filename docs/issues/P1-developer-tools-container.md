# OS-012: Developer tools container

**Priority:** P1 · **Release target:** Beta

## Problem

VS Code, terminal, Git are registry entries and mocks (`wsl_dev_tools.py`).

## Why it matters

College CS/STEM students need to code and push to GitHub.

## Definition of done

- Terminal in container or native shell
- Python + Git available
- VS Code Web or code-server route works

## Tests

- Clone repo, run script, git push smoke

## Evidence required

- Demo log

## Non-goals

- Full Cursor desktop
- Docker-in-Docker on device v1

## Claim boundary

Dev environment prototype. Not certified for all course toolchains.
