# OS-004: Real notes/PDF baseline

**Priority:** P0 · **Release target:** Beta

## Problem

Notes and PDF apps are tiles/placeholders only.

## Why it matters

Core student workflow: take notes, read/annotate syllabi and papers offline.

## Definition of done

- Notes app: create, edit, list, delete notes; persist across restart
- PDF: open and scroll local PDF (annotation optional v1)

## Tests

- Notes persist test
- PDF open smoke with sample file

## Evidence required

- Test log

## Non-goals

- Full PDF annotation suite
- Cloud sync

## Claim boundary

Local-only v1. No claim of Adobe/competitor parity.
