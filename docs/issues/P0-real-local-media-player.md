# OS-007: Real local media player

**Priority:** P0 · **Release target:** Beta

## Problem

Local media card is placeholder; Offline Mode policy allows local media but nothing plays.

## Why it matters

Offline study includes downloaded lectures and owned media files.

## Definition of done

- HTML5 player plays user-selected MP4/WebM/MP3
- Works in Offline Mode UI (streaming cards hidden)

## Tests

- Play sample file test
- Offline mode hides Netflix/Hulu

## Evidence required

- Playback screenshot + test log

## Non-goals

- DRM-protected local files
- Full media library app

## Claim boundary

Non-DRM files only. No circumvention.
