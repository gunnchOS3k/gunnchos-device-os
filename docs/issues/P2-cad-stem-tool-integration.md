# OS-020: CAD/STEM tool integration

**Priority:** P2 · **Release target:** RC / GA

## Problem

STEM hub, Jupyter, MATLAB Online, KiCad, FreeCAD are placeholders or web links.

## Why it matters

STEM college students need notebooks, CAD, simulation.

## Definition of done

- Jupyter in container OR MATLAB Online route verified
- One CAD web route (Onshape) works in browser shell

## Tests

- Notebook execute smoke

## Evidence required

- Demo log

## Non-goals

- Full MATLAB desktop
- All STEM packages locally

## Claim boundary

Web/container routes. Heavy compute may be cloud per product vision.
