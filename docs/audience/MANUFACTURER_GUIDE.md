# Manufacturer Guide

How to build and flash gunnchOS device images for Student, DS-XL, Handheld, and dock host SKUs.

## Scope

- Image assembly from reproducible build inputs
- Factory station software runner (simulated HAL today)
- Serial, HW/SW revision, and station/operator fields in test records

## Not in this guide

Physical EVT bring-up procedures that require lab hardware remain separate. This guide covers the digital manufacturing software path.
