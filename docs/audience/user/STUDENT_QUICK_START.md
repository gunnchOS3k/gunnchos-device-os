# Student Quick Start

Welcome to gunnchOS for school.

1. Sign in with your school profile
2. Open WAIKE for coursework
3. Read PDFs, take notes, and write code in Creator Studio
4. Ask the on-device study helper when you need a hint
5. Save and export your work
6. Keep working offline — your changes sync when you reconnect

Tip: Dock at a desk to use a larger display and keyboard.
