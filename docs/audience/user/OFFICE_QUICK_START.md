# Office Quick Start

gunnchOS for everyday work.

1. Sign in
2. Browse the web and open documents, sheets, or decks in LibreOffice
3. Export or print to PDF
4. Join meetings in the browser (allow camera/mic when prompted)
5. Attach files from your export folder
6. Dock for an external display, then save before you leave

Your files stay on the device unless you choose to sync.
