# VXP Baseline Matrix

| Surface ID | Pre-VXP pattern | Baseline problem | VXP-1 target |
|---|---|---|---|
| home | Flat shortcut buttons | No identity hierarchy; dashboard of equal CTAs | Living Workspace: Continue / Spaces / Status |
| vault | Path·size·mime·sha one line | Hash noise before name | Name/type/size/modified; details for SHA/MIME |
| app_center | Dense metadata row | Action buried | Identity + status + primary action |
| connect | Form + empty inbox | Generic empty | Honest empty + Living chrome |
| assist | Raw checkboxes | Weak labels | Labeled assist rows + focus |
| care | Backup list first | No health hierarchy | Health → backups → recovery |
| wallet/portfolio/career/verifier | Functional CX3 panels | Visual inconsistency | Shared surface header + tokens |
| nav | 10 equal top buttons | Crowded handheld | Dock 5 + More; rail on wide |
| offline/error | Banner text | No icon language | Icon + honest copy |

Responsive targets: 360–430, 700–930, 768×1024, 1366×768, 1440×900, 1920×1080.
