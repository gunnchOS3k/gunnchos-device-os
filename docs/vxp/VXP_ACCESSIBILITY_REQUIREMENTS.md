# Accessibility Requirements

Required in VXP-1 (no WCAG certification claim):
- Focus-visible rings on interactive controls
- `aria-current=page` on active nav
- Assist: high contrast, reduce motion, UI scale with visible labels
- Touch targets ≥ 44px
- Keyboard: Alt+1..0 surface jump, Escape back, Alt+H home
- Offline/error use `role=status` / `role=alert`
- HUMAN_A11Y_PENDING until human packet completed
