# Information Architecture

## Primary navigation

Handheld: bottom dock — Home, Vault, App Center, Connect, More.
Desktop/landscape (≥900px landscape or ≥1100px): side rail — same five, More expands Assist/Care/Wallet/Portfolio/Career/Verifier.

## Surface IDs (stable)

`home`, `vault`, `app_center`, `connect`, `assist`, `care`, `wallet`, `portfolio`, `career`, `verifier`

## Utility chrome

Back / Home / Exit are **utility**, not a second equal-weight primary row.
