# gunnchOS Device OS

## What is it?
School-ready, research-aware edge OS layer for gunnchOS devices—not a replacement for Windows/iPadOS wholesale, but a **mode-based** research/product stack.

## Modes
School · Developer · Play · Research Measurement · Fleet Admin

## Demo
```bash
make e2e
cd apps/launcher_mock && npm run build
```

## Not claimed
- Not final 6G certification or operational 6G hardware
- Not FCC/CE/UL/UN38.3 certified
- Not manufacturing-ready or carrier-grade
- Research prototype / EVT planning only
