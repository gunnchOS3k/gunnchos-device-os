**Title:** Add PhD application readiness documentation

**Body:**

Adds PhD application readiness documentation to the gunnchOS device OS repository.

## Summary
- Adds `docs/PHD_APPLICATION_READINESS.md` with repository role, status, metrics, and boundaries
- Adds `docs/service-aware-middleware-architecture.md` with complete middleware architecture specification including Mermaid diagram, service/device/network profiles, degradation behavior, security modes, and simulation boundaries

- Service profiles are fully implemented
- Network selection is operational
- Real users have been tested
- Live 6G access exists or is required

## Framing
gunnchOS is documented as a service-aware middleware research concept — a decision layer mapping user activity to connectivity, computation, energy, security, and quality-of-experience requirements for studying 6G service continuity.
