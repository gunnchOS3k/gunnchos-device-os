# Component to OS Feature Map

| OS feature | Required component signals |
|---|---|
| School Mode | display, input, storage, network optional |
| Developer Mode | RAM ≥8GB, storage ≥256GB, x86 for WSL path |
| WSL path | x86-64, RAM ≥16GB recommended |
| Steam path | x86-64 APU, active thermal, controller |
| Media Mode | display, audio, storage |
| Studio Mode | RAM, storage, display |
| Laboratory Mode | network, consent gate, Edge-IO stub |
| Offline Mode | local storage |
| Dock/external display | USB-C DP Alt Mode contract (simulated) |
| Accessibility | input/display contracts |
