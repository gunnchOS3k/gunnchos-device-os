# Feedback

For Ecosystem RC1, the **public feedback front door** is the research portal:

- Guide: https://github.com/gunnchOS3k/gunnchos-research-portal/blob/release/v1.0.0-rc1-ecosystem-freeze/FEEDBACK.md
- Issue forms: bug, feature, experience, research, hardware, accessibility, documentation
- Security: private advisories only — see [SECURITY.md](SECURITY.md)

Component-specific templates in this repo (if any) are preserved for specialized workflows; prefer the portal when unsure.
