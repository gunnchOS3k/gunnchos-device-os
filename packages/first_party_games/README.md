# First-party game packages

Accepted-SHA manifests + imported artifacts for gunnchOS.

- **beatlink-party**: web dist + server dist imported from accepted Cont VI tip
- **anime-aggressors / archive / pedestrian**: workspace artifact manifests
  (import via `scripts/import_first_party_packages.py` — do not vendor full repos)

`STUB_AS_PRODUCT` is forbidden. Each `PACKAGE_MANIFEST.json` records source repo,
accepted SHA, build command, artifact hash, permissions, and device roles.
