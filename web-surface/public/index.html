# Reproducibility — gunnchos Device OS Paper I infrastructure for *Resilience-Aware Service Continuity in Heterogeneous 6G Networks*. Not a shipping OS. Not physical boot. ## Clone / setup / run ```bash git clone https://github.com/gunnchOS3k/gunnchos-device-os.git cd gunnchos-device-os python3 -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\activate python3 -m pip install pytest pyyaml python3 -m pip install -r requirements.txt make reproduce ``` Canonical independent path is **`make reproduce`**. Full `pytest -q` is the CI suite (longer; requires the jobs in `.github/workflows/ci.yml`). Launcher UI prototype (optional): ```bash cd apps/launcher_mock && npm ci && npm test `
