# School / Library Deployment Legal Checklist

## School deployment

- [ ] District data processing agreement
- [ ] FERPA alignment review
- [ ] MDM enrollment consent
- [ ] Incident response plan
- [ ] Device loss/theft procedure

## Library deployment

- [ ] Patron privacy policy
- [ ] Session timeout enforcement
- [ ] Guest account data deletion
- [ ] CIPA considerations for filtered internet (network layer)

## Shared

- [ ] Accessibility accommodation policy
- [ ] Terms of use acceptance flow
- [ ] Insurance / liability review

**Requires qualified legal review before production deployment.**
