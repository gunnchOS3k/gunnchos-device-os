# AI Assistant Data Boundary

**Status:** UI shell only — no backend in GunnchOS prototype.

## Current behavior

- AI panel is a visual placeholder in the launcher shell
- No prompts transmitted to any model provider from GunnchOS code
- `aiPrivacy` toggle in settings persists locally only

## Future integration requirements (not implemented)

- Explicit consent before first prompt
- Data minimization and retention limits
- No training on student data without guardian/school agreement
- Regional data residency review
- Vendor DPIA before integration

## Claim boundary

Do not claim "AI privacy mode" provides legal protection until backend architecture is reviewed and documented.
