# Data, Databases, and Dashboards

A dashboard that cannot be rebuilt from a CSV is decoration. Start with group-by and top-N. Gary logged 20 lab hours, Ghana 5, Geelong 9 — the wall chart should match the arithmetic, not a designer’s guess.

The lab sums a metric by site and returns the top two. Ties break alphabetically. You will then sketch the same table on paper so a sponsor who hates charts can still read the ranking.
