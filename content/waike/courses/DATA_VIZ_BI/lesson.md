# Data Visualization and Business Intelligence

A histogram is a count of values that fell into edges. Edges [0,3,6,10] make three bins: [0,3), [3,6), [6,10]. The last bin includes the right edge so 10 does not fall on the floor. Values 1,2,2,5,9 → counts 3,1,1.

Sponsors understand bins better than kernel density. Owner file is a stub. This seed is binning plus a sentence you could say in a budget meeting.
