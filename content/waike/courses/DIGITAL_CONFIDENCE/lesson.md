# Digital Confidence to Computer Operator

Operator confidence is not 'being good with computers.' It is knowing which of three jobs you asked the machine to do: remember (files), calculate (apps), or talk (network). Beginners freeze when a window disappears because they cannot name the job that failed.

Today you will build a folder tree by hand: Documents/waike/lab1 plus a Downloads inbox. You will copy a note into lab1, then recover it after a 'delete' drill. Mouse-only habits hide the path; keyboard and path names survive when the GUI theme changes on a shared lab PC in Gary.

Safety: never store passwords in the note. If a USB stick appears, treat it as untrusted until an instructor says otherwise. Offline pack: this lesson runs with no internet — the tree lives on disk.
