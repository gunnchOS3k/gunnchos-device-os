# AI/ML and Edge AI Foundations

Edge AI in this seed is 1-nearest-neighbor in 2-D. No GPU, no cloud, no 'training pipeline.' You store a few labeled points and assign each query the label of the closest training point by squared Euclidean distance.

That is enough to feel the difference between a local decision and an API call. It is not a claim of model quality. gunnchAI tutoring here is a Socratic hint, not an inference server.

Try moving a query across a decision boundary on paper before you run the lab.
