# Robotics and Control

A proportional controller does one thing: delta = Kp * error. Heading 10°, target 30°, Kp=0.5 → you add 10° and land at 20°. You did not arrive yet. Large Kp overshoots; you can feel it by turning a chair too fast toward a tape mark.

This is not PID, not a rover, not ROS. Owner file is a stub. The seed is one step and a warning about gain.
