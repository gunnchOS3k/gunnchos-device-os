# Software Builder Zero-to-Hero

Shipping is smaller than 'becoming a developer.' A stranger must run what you wrote. That means a function with checks, a README with one command, and no secrets in the repo.

This seed grades numeric scores into bands: H (≥90), M (≥75), L (≥50), R (retry). The bands are arbitrary on purpose — you will change thresholds later. What you must not skip: run the checks. A function that 'looks right' is not a lab pass.

Kinesthetic: write the band table on paper, then type it. If paper and code disagree, the paper wins until you find the bug.
