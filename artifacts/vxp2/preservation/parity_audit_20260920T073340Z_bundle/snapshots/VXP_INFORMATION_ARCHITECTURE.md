# Information Architecture

**Contract target (VXP-2):** Shared navigation grammar is Home, Apps, Search/Command, Continuity, Notifications/Status, Settings — see [`docs/product/GUNNCHOS_DEVICE_PARITY_CONTRACT.md`](../product/GUNNCHOS_DEVICE_PARITY_CONTRACT.md). Missing slots below are gaps, not reduced-phone identity.

## Primary navigation (VXP-1 implemented)

Handheld: bottom dock — Home, Vault, App Center, Connect, More.
Desktop/landscape (≥900px landscape or ≥1100px): side rail — same five, More expands Assist/Care/Wallet/Portfolio/Career/Verifier.

## Surface IDs (stable, implemented)

`home`, `vault`, `app_center`, `connect`, `assist`, `care`, `wallet`, `portfolio`, `career`, `verifier`

Not yet first-class shell routes (contract gaps): WAIKE, gunnchAI, Games library, Creation, Leisure, Search/Command, Settings, Continuity module.

## Utility chrome

Back / Home / Exit are **utility**, not a second equal-weight primary row.
